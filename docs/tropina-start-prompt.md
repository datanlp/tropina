# Tropina — карта рождественских ярмарок Польши (MVP)

Ты — мой агент-разработчик в этом репозитории. Пишем первый кусок будущей карты Tropina: карту рождественских ярмарок Польши. Срок — около недели, запуск вместе с постом в моём Instagram. Работай этапами (ниже), после каждого этапа останавливайся и показывай результат.

## Контекст продукта

- **Tropina** — будущая карта локальных маршрутов, еды и событий по Европе (сначала Польша, потом Италия). Ярмарки — первый слой. Всё, что делаем сейчас, должно жить дальше в этом же приложении: этот репозиторий — основа большой карты, а не одноразовый лендинг.
- Пользователь хочет за минуту понять: где в Польше рождественские ярмарки, когда они работают, что там поесть и как добраться.
- Аудитория: поляки, туристы и мой русскоязычный блог. Языки интерфейса и контента: **en** (основной), **pl**, **ru**.
- Домен: `tropina.app`.

## Стек (не меняй без согласования)

- **Next.js (App Router) + TypeScript strict.** Версия Next новее твоих знаний: перед кодом прочитай `AGENTS.md` и документацию в `node_modules/next/dist/docs/`, следуй ей, а не памяти.
- **MapLibre GL JS**, подложка **OpenFreeMap** (`https://tiles.openfreemap.org/styles/liberty`), без API-ключей. Атрибуция OpenStreetMap обязательна.
- **next-intl** (или актуальный аналог из документации Next) для переводов. Ни одной строки интерфейса прямо в коде.
- **zod** для схемы данных. Данные лежат в репозитории, бэкенда нет.
- **PWA**: `app/manifest.ts` + service worker с офлайн-кэшем. Библиотеку для SW (например, Serwist) выбери только после проверки совместимости с нашей версией Next.
- **Аналитика без cookies** (Umami или Plausible) через обёртку `track(event, props)`, чтобы провайдера можно было сменить. Баннер согласия не нужен — именно поэтому без cookies.
- **Хостинг: Vercel.** Тариф Hobby годится только для некоммерческого использования; когда появятся партнёрские ссылки, переедем на Pro или в другое место. Ничего не завязывай на специфику Vercel.

**Не делаем сейчас:** бэкенд, Supabase, логины, Mapy.com (их ключ во фронте был бы виден всем), свой роутинг, cookies, год в адресах.

## Адреса (постоянные)

```
/{lang}/poland/christmas-markets                    — вся Польша: карта + список
/{lang}/poland/christmas-markets/{city}             — все ярмарки города
/{lang}/poland/christmas-markets/{city}/{market}    — одна ярмарка
```

- `lang` ∈ `en | pl | ru`. Корень `/` определяет язык браузера и перенаправляет (по умолчанию `en`).
- Слаги латиницей без диакритики: `krakow`, `rynek-glowny`.
- Если в городе одна ярмарка, страница города перенаправляет на неё.
- Года в адресе нет: страница ярмарки вечная, каждый сезон обновляются только даты.

## Схема данных (`src/data/markets/*.ts`, валидация zod)

```ts
type L10n = { en: string; pl: string; ru: string };

type Market = {
  id: string;                 // "krakow-rynek-glowny"
  country: "poland";
  city: { slug: string; name: L10n };
  slug: string;               // "rynek-glowny"
  name: L10n;
  location: { lat: number; lng: number; address: string };
  season: { start: string; end: string };      // ISO-даты, Europe/Warsaw
  openingHours: {                               // для фильтра «открыто сейчас»
    days: (1|2|3|4|5|6|7)[];                    // 1 = понедельник
    open: string; close: string;                // "10:00", "21:00"
  }[];
  hoursNote?: L10n;           // исключения: «24.12 до 14:00» и т.п.
  food: { name: L10n; note?: L10n }[];
  description: L10n;
  transport?: L10n;
  accessibility?: L10n;
  officialUrl: string;        // обязательна
  verified: boolean;          // даты сверены с официальным источником
  lastChecked: string;        // ISO-дата проверки
  suggestedBy?: string;       // ник подписчика, который посоветовал ярмарку
};
```

- Сборка **падает**, если у ярмарки нет дат, ссылки на официальный сайт, координат или перевода на любой из трёх языков.
- Неподтверждённые даты (`verified: false`) показываются с явной пометкой.
- Карточки 8 городов (Краков, Вроцлав, Гданьск, Торунь, Варшава, Катовице, Познань, Ополе) я дам сама. До этого сделай 2 тестовые записи с пометкой `TEST`, которые не попадают в продакшен-сборку.

## Что видит пользователь

1. **Карта Польши** с маркерами ярмарок (кластеризация при отдалении) и **список рядом, синхронный с картой**: выбор в списке подсвечивает маркер, и наоборот. На телефоне — переключатель «Карта / Список».
2. **Фильтры:** «Открыто сейчас», «В эти выходные», «Все». Время считается по Europe/Warsaw. Прошедшие ярмарки скрыты; на их собственной странице написано «сезон закончился, ждём в следующем году».
3. **Карточка ярмарки:** даты, часы (+ исключения), что поесть, как добраться, доступность, кнопки «Как добраться» (ссылка `https://www.google.com/maps/dir/?api=1&destination=lat,lng`) и «Официальный сайт», пометка проверки и дата проверки, «Посоветовал(а) @ник», если есть.
4. **Страницы города и ярмарки** с собственными meta-тегами, `hreflang` для трёх языков, `sitemap.xml` и разметкой JSON-LD `Event` для каждой ярмарки.
5. **Установка на телефон:** предложение появляется после того, как человек открыл вторую карточку, а не сразу. На Android — системный prompt, на iOS — короткая инструкция «Поделиться → На экран „Домой“». Офлайн работает карта уже открытых мест и все карточки.
6. **События аналитики:** `market_open`, `official_link_click`, `directions_click`, `filter_change`, `install_prompt_shown`, `app_installed`, `lang_change`.

## Доступность (WCAG 2.2 AA — с первого дня, не «потом»)

- Список — полноценная альтернатива карте: всё, что есть на карте, доступно скринридеру через список.
- Всё работает с клавиатуры, фокус всегда видим, зоны нажатия не меньше 24×24 px.
- Информация не передаётся только цветом. Контраст проверен.
- `prefers-reduced-motion` отключает анимации карты.
- `eslint-plugin-jsx-a11y` в линтере; **axe в каждом Playwright-тесте**: нарушение — тест красный.

## Тесты и барьеры

- TypeScript strict, ESLint (включая a11y), Prettier.
- **Vitest** для логики дат: «открыто сейчас», «в эти выходные», «сезон закончился», переходы через полночь, часовой пояс Варшавы, исключения 24–26 декабря.
- **Playwright + @axe-core/playwright**: главная, страница города, страница ярмарки, фильтры, смена языка, переход по ссылке «Как добраться». На мобильном и десктопном viewport.
- Схема данных проверяется при сборке (zod).
- Сначала тест, потом код. **Никогда не меняй тест, чтобы он прошёл** — если тест кажется неверным, остановись и спроси меня.
- Перед словом «готово» прогони: typecheck, lint, unit, e2e, build.
