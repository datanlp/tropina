# Tropina — контекст и принятые решения

Фон для агента. Если что-то здесь расходится с `tropina-start-prompt.md`, для текущего MVP прав стартовый промпт.

## Название и домен
- Название: **Tropina** (корень trop/тропа + итальянское -ina, «тропинка»). Читается одинаково по-польски, итальянски, русски.
- Домен: `tropina.app` (возможно, ещё `tropina.eu`; `trapina.app` — редирект для тех, кто пишет на слух).
- Instagram продукта: `@tropina`, ведётся только на английском.

## Языки
- Сайт: en (основной), pl, ru. Итальянский — когда карта придёт в Италию.
- Ни одной строки интерфейса в коде; у контента в данных поле на каждый язык.

## Первый релиз: рождественские ярмарки Польши
- 8 городов с проверенными данными: Краков, Вроцлав, Гданьск, Торунь, Варшава, Катовице, Познань, Ополе.
- Запуск: пост в профиле автора, затем призыв к подписчикам советовать ярмарки. Советы — подсказка, даты всегда сверяются с официальным источником. Автор совета указывается на карточке (`suggestedBy`) — это начало программы контрибьюторов.
- В слое только рождественские ярмарки (никаких других праздников), цель — вся Польша.
- Обновление данных перед сезоном: прогон в сентябре и повторный в конце октября.

## Куда идёт продукт (не делать сейчас, но не мешать этому)
- Большая карта: маршруты (с логикой соединения троп), слой локальной еды с градацией «насколько блюдо местное», рестораны, привязанные к блюдам, жильё, hidden gems.
- Человек рисует маршрут — видит местные блюда в коридоре 5–10 км и рестораны, где их делают.
- Рестораны сами привязываются к блюдам (бесплатно на старте), позже — платное выделение и отчёт по статистике.
- Контрибьюторы: фото блюд от пользователей, бейджи за одобренные вклады; таблица вкладов с первого дня, чтобы выдать бейджи задним числом.
- Сезонный слой событий с датами действия — общий механизм для ярмарок, позже сагр, пасхальных ярмарок и т.п.
- Статистика с первого дня: показы, клики, «проложить маршрут» — для отчётов партнёрам.
- Целевой стек большой карты: Next.js + FastAPI (Python) + Supabase (Postgres + PostGIS), Mapy.com для подложки и маршрутов, позже свой роутер и ИИ-слой. Сейчас — только фронт.
- Доступность (WCAG 2.2 AA) и безопасность — с первого дня, не «потом».
- Позже — Италия и другие страны ЕС; страна всегда в адресе.

## Тон и контент
- Журнал разработки — сырьё для постов в LinkedIn и блоге автора; только факты, без секретов и личных данных.
- В русских текстах о Польше — «гжанец» (grzaniec), не «глинтвейн».
