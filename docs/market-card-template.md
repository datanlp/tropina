# Карточка ярмарки: шаблон

Одна ярмарка = один такой блок. Можно прислать текстом, таблицей или файлом, в любом
порядке. Достаточно одного языка: переводы на en/pl/ru/uk сделает агент (в русском —
«гжанец», не «глинтвейн»). Обязательные поля помечены **\***, без них сборка не пройдёт.

```
Город*:                 Kraków
Название ярмарки*:      Jarmark Bożonarodzeniowy na Rynku Głównym
Адрес*:                 Rynek Główny, 31-042 Kraków
Координаты*:            50.0617, 19.9373   (правый клик в Google Maps → первая строка)
Даты*:                  2026-11-27 — 2026-12-26
Даты подтверждены?*:    да / нет (нет = на сайте будет пометка «даты не подтверждены»)
Когда проверяли*:       2026-11-15
Официальный сайт*:      https://...
Часы работы*:           пн–чт 10:00–21:00; пт–вс 10:00–22:00
Исключения:             24.12 10:00–14:00; 25.12 закрыто
Комментарий к часам:    (свободный текст, если что-то сложное)
Что поесть:             гжанец; осципек с клюквой — подают горячим; ...
Описание*:              2–3 предложения, чем ярмарка хороша
Как добраться:          трамваи до остановки ...; парковка ...
Доступность:            ровная брусчатка, туалет для колясок у ...
Предложил(а):           ник автора, если ярмарку подсказал читатель
```

## Что агент сделает с карточкой

1. Создаст файл `src/data/markets/{город}-{ярмарка}.ts` (латиница без диакритики:
   `krakow`, `rynek-glowny`) и зарегистрирует его в `src/data/markets/index.ts`.
2. Переведёт тексты на четыре языка.
3. Прогонит `npm run validate:data` и все тесты.
4. Когда придут настоящие карточки всех восьми городов, удалит
   `src/data/markets/placeholder/` (LOREM).
