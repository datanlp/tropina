# Проверка на телефоне (этап 6)

Нужно: iPhone (Safari) и Android (Chrome), адрес сайта (превью на Vercel). Займёт ~15 минут
на телефон. Пишите номер пункта и что не так; скриншот помогает.

## Перед проверкой

Сайт должен быть доступен по ссылке. Проще всего: подключить репозиторий к Vercel (бесплатный
тариф Hobby) и в Settings → Environment Variables добавить `TROPINA_INCLUDE_PLACEHOLDER_DATA`
= `1` **только для Preview**. Тогда превью покажут LOREM-ярмарки, а продакшен — только
настоящие.

## Пункты

1. Открыть `/` — попадаете на список ярмарок на языке телефона (en, pl, ru или uk).
2. Список читается без зума, ничего не уезжает за край экрана.
3. Кнопка «Карта» показывает карту Польши с метками; карту можно двигать двумя пальцами,
   одним пальцем страница прокручивается.
4. Нажать на метку → появляется название со ссылкой на карточку; ссылка открывает карточку.
5. Фильтры «Открыто сейчас» / «В эти выходные» / «Все» меняют список.
6. В карточке: «Как доехать» открывает карты телефона (Apple Maps / Google Maps),
   «Официальный сайт» открывает сайт ярмарки.
7. Переключить язык в шапке — та же страница на другом языке.
8. Открыть вторую карточку → снизу подсказка «Установить». iPhone: инструкция «Поделиться →
   На экран „Домой“». Android: кнопка «Установить» открывает системное окно.
9. Установить, открыть с главного экрана: открывается без адресной строки, иконка красная с «T».
10. Включить авиарежим, открыть из установленного приложения любую карточку — открывается.
11. Только iPhone: Настройки → Универсальный доступ → VoiceOver (или Android: TalkBack),
    пройти список свайпами — названия ярмарок и кнопки читаются понятно.
12. Крупный шрифт (Настройки → Экран → Размер текста на максимум): текст не обрезается.
